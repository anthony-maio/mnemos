# Hermes lifecycle and provisional-capture checkpoints

The verified successor is `5e4b057b16906c2ec7dd302ae80748ef1ac5eddc`.
It passes 1,195 source tests with four skips, all six source/package checks,
507 isolated installed contract cases with two matching skips, and seven
synthetic replay assertions. The 297,814-byte wheel SHA-256 is
`7eaba268fb91ffae7d59b222cf8addb49d8b4b4857a37552e5404422e4009625`.

The installed Hermes MemoryManager API run passes using that same wheel,
Hermes `14a346345486418aa85ed6526549412ee2665ade`, and the actual Windows/WSL
bridge and local service. Its 16 calls cover the six scoped tools, explicit
remember, correction, inspected versions, forgetting, foreign-scope denial,
job status, and fallback-capture inspection. Repeated callbacks across growing
transcripts, checkpoints, and provider recreation persist four normal events.
Two callbacks without a transcript persist four separate provisional receipts;
maintenance cannot extract facts from those receipts.

This is installed host API evidence with fixture embeddings, unavailable
cognition, and disabled modules. It is not a native model conversation, a CLI
scope-propagation check, an outage recovery result, or an extraction-quality
result. The earlier [patched CLI v4](../native-hermes-local-v4/README.md)
retains its separate real-model, single-turn evidence. Neither run changes
live host configuration or closes complete native lifecycle acceptance.

The first candidate, `b7d75000e453fc9510a6a7148da2998ed6e3f103`, passed
1,194 source tests, 506 installed cases, replay assertions, and the narrower
API v1 check. Two subsequent regressions failed against its installed wheel:
the service rejected provisional Hermes evidence, and the explicit-write
schemas omitted the required request identity. Both failures are preserved
under `candidate-regressions`. The successor repairs and tests those gaps;
the earlier passing counts did not establish the missing behavior.

Occurrence hashes bind submitted fields, not cryptographic host authorship.
The service trusts authenticated adapters to report host evidence accurately.
The same provisional event cannot become extractable; a later actual transcript
can create a distinct normal occurrence with the same text. Receipt counts
therefore do not measure independent observations or complete capture coverage.

`evidence-index.json` records the hashes and sizes of 81 raw artifacts, including
both source/install records, selected API outputs, the two failed regressions,
and executed helpers. Credentials, runtime descriptors, and fixture databases
are omitted. The frozen model comparisons remain bound to `fc72cc2`; this
checkpoint does not replace their source or reinterpret their failures.
