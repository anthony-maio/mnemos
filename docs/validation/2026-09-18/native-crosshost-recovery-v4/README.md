# Native mixed-host replay and restart

The bounded same-event replay and restart probe passed on Codex CLI 0.146.0 and Claude Code 2.1.191, using the installed `fc72cc2` package. Both hosts first completed a synthetic turn while malformed disposable configuration prevented service startup. Five events remained queued and the database retained only its two seeded controls. After explicit owner restoration, fresh native processes replayed the shared outbox automatically through unchanged hooks.

Three normal queued events received overlapping deliveries from both native hosts. Windows TCP ownership and process ancestry identify the replaying Codex and Claude processes independently of each event's source-host metadata. Each pair returned committed status with the same durable event ID and job ID. Measured request overlap was 12.3995, 12.8659, and 13.1764 ms. Recovery processes overlapped for 10.515 seconds. One earlier request expired at the unchanged two-second pairing deadline and remained a timeout in the report; its subsequent commit does not reclassify it as a paired request.

All four native turns exited zero. The outbox emptied. Eight normal native messages across four sessions each have one completed extraction job and one scoped fact-evidence link. Two additional Claude user observations remain deferred with completed capture-only jobs, identity-pending results, and no extracted facts. Native UUIDs, Codex turn identities, source line/file hashes, scoped provenance, assistant attribution, and both control facts were verified. Complete-row hashes for facts, source events, jobs, and evidence stayed unchanged after maintenance, close, owner restart, and final cleanup. Temporary credentials and the runtime descriptor were removed. The independent archive verifier also checked all 58 wheel-owned package files and SQLite integrity.

The earlier [v3 failure](../native-crosshost-recovery-v3/README.md) is unchanged. Its shim retained an expired first arrival instead of tracking active waiters. The new protocol pairs only live requests for the same source event from different expected native hosts, expires waiters atomically, and accepts an event at most once. It does not increase the deadline or offset host launches. Eight shim checks cover these boundaries. The revised capture verifier also passes four read-only checks against the preserved v3 database, and seven preflight checks cover transcript selection, provenance, and TCP attribution. The protocol was hashed before native execution and is included verbatim.

Claude reported `identity_reference_unavailable` during prompt submission and `ambiguous_transcript_association` at Stop even in recovery. Its native hook processes exited zero, but these degraded diagnostics keep complete hook acceptance open. The selected diagnostic artifact retains exact fixed reason codes; repeated copies across stream fields are identified as such. Optional modules were disabled, vectors were lexical fixtures, cognition was unavailable, the owner was explicitly restored, and replay overlap was instrumented.
