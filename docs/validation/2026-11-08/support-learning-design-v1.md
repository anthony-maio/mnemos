# Support learning design and asset inspection

The next semantic design is a joint-cohort classifier with task-specific support supervision. A shared forward pass reads the question and complete retained candidate/source cohort; structurally recorded target positions feed a shared classification head. This changes the inference topology as well as the learning objective. Reusing a backbone alone would not constitute the topology change.

Review identified prerequisites now included in the [protocol](../../plans/2026-11-08-joint-support-learning-v1.md): group templates, paraphrases, counterfactuals and shared source facts before splitting; bind marker positions in the serializer instead of finding them in source text; handle padding/count/order without losing target identity; grade joint conflicts rather than assuming shared attention prevents them; and separate inference capacity from training memory. The protocol is concrete enough for data and serialization preparation. The corpus, numerical training recipe and capacity result do not yet exist.

Read-only inspection verified all 12 retained Qwen3-Reranker-0.6B model-file hashes against the original execution freeze. Safetensors headers contain 595,776,512 BF16 tensor elements, with Qwen3ForCausalLM architecture. The retained runtime contains torch 2.10.0+cu128, transformers 4.57.6 and safetensors 0.8.0; peft and datasets are absent. No dependency was installed and no model weights were loaded for inference. Exact inspection helper and result are retained at `.venv/inspect-support-training-assets-v1.py` and `.venv/support-training-assets-v1.json`.

The previous runner already used `logits_to_keep=1`; eliminating all-token vocabulary logits is not an unused optimization. Its 375.64 ms support p95 covered at most three witnesses and excluded retrieval. That result cannot establish the new candidate's capacity or complete latency. All prior failed semantic configurations remain closed, with original scores intact. No training, new model call, acceptance data, live activation or pilot use occurred here.
