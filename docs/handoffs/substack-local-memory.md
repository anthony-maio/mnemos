## Capture tradeoff and user context

Anthony asked about automatic conversation capture versus only saving facts an agent explicitly selects. Do not turn the question into an already accepted deployment preference. Automatic capture preserves evidence and reduces missed context, but adds noise, private material, processing cost and opportunities to recapture stale claims. Explicit selection makes intent clearer and reduces volume, but depends on the agent noticing what matters and calling the tool.

The design direction is hybrid: capture locally in enabled projects, conservatively promote supported facts, provide explicit remember/correct/forget operations, and retain source-backed explanations. Captured conversation is not automatically an asserted fact. Reliability of that promotion is still being tested.

Anthony reported that the remote dual-3090 machine failed and the work moved to a local RTX 4080 with 16 GB. Colab was considered and tabled. This is user-reported hardware history; do not infer an electrical cause or a controlled hardware comparison. Include it only if it explains the experimental constraints.
