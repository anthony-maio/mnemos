native model must retrieve the seeded fact, inspect that exact ID, and return
its source-backed guide path plus the disposable marker. Require a successful
native terminal record, the pinned model, exact advertised tool set and strict
call/result correlation. Bind the trace parser explicitly to `mcp__mnemos__`;
do not rename raw tool records into the older plugin namespace.

and the assistant's guide/marker reply. Require their physical project,
profile and session identities to match the native invocation. Preserve event
metadata and fact assertion categories; raw capture is not accepted extraction.

the first failure without rewriting its outcome.

Always stop the owned service, remove copied authentication, and verify that
the actual pilot has neither a service directory nor a database. Its launcher,
settings, registry and installation record, and both source credential files,
must remain byte-for-byte unchanged. Keep prompts, streams, project identity,
configuration and database evidence private. Publish sanitized results only.

The [Claude settings guide](https://code.claude.com/docs/en/settings) separates
shared project and local settings. The [MCP guide](https://code.claude.com/docs/en/mcp)
documents different project-approval behavior for interactive and print-mode
sessions. Those current docs guide the invocation; the pinned binary's actual
records must establish behavior. This test does not validate interactive
approval, Codex hooks, compaction, outage recovery, automatic extraction,
quality gates or daily-use coverage. No pilot day or live activation follows.
