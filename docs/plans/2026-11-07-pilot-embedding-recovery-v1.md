# Installed pilot embedding recovery v1

Freeze this protocol and runner before one installed attempt. Use product
`6d0e5ba6`, its verified wheel and persistent pilot interpreter. Verify every
installed package byte against the wheel. Copy the unchanged launcher and
settings into a fresh protected disposable root, changing only root paths and
registering two new physical project identities. Keep the real pilot inactive.

Start the normal service and background scheduler with its default dispatcher
factory. A test subclass intercepts only the real FastembedProvider vector call:
while a controller flag is set, raise MnemosTransientError. Before that fault,
use real BGE-small vectors to store one explicit project control and one foreign
control. Do not substitute vectors, disable maintenance, edit jobs, advance the
clock or change provider configuration. Record every intercepted call.

During the fault, accept one explicit write and one raw capture through the
authenticated client. Force one maintenance pass and require two pending jobs,
refunded attempts, recorded provider failures, released leases and future retry
times. Both original events must be durable with no new facts. The scoped job
API must report pending work. Existing project recall must report lexical-only
degradation with no semantic score; foreign and unprocessed markers must not
appear as facts.

Stop that service and restart through ordinary installed client auto-start,
without the test subclass. Keep the configured real provider and scheduler.
Wait at most 60 seconds for the unchanged backoff to permit maintenance. Require
one completed explicit fact and one completed unasserted raw chunk, with both
controls intact. Real semantic recall must recover, raw capture must remain
excluded from ordinary recall, and exact replay plus a second ordinary restart
must preserve complete event/job/chunk/evidence/revision rows.

Preserve the first failure and do not silently retry. Verify SQLite integrity,
foreign keys, source pilot hashes, normal child-process exit and descriptor
removal. Archive the original configuration, source hashes, provider calls,
API results, snapshots and final report privately before writing public claims.

This tests recovery from an injected typed provider exception. It does not
establish which native ONNX failures receive that exception type, provider
initialization failure, a naturally occurring outage, host-hook deadlines,
mid-write crash behavior, extraction quality, repeated reliability or pilot
days. There is no native model invocation and no live host configuration change.
