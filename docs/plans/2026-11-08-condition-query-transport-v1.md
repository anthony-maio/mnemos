# Condition-query execution boundary

`benchmarks/local_memory/condition_query.py` connects the authored condition request to an asynchronous provider and the existing evidence binder. A completed provider reply is bound to the invoking request. The adapter checks the request before sending, checks revision fences before and after interpretation, preserves completed raw text for diagnosis, and evaluates applicability only after the complete query interpretation passes structural validation.

Results distinguish `interpreted` from `unavailable`. An unavailable result has no applicability value: a timeout, malformed reply or stale revision must not count as a correct unresolved answer. An interpreted result still contains model judgments, not verified semantic entailment. A unique substring can be an irrelevant witness; the eventual probe must grade that separately.

Execution makes one attempt with an asyncio 15-second timeout and no retry. Owner cancellation propagates rather than becoming a result. This timeout relies on cooperative transport cancellation; it is not a guarantee that a remote generation process has stopped. A runtime owner must retain full requests and replies, confirm provider termination after uncertain completion, and stop serial advancement when termination cannot be verified. The transport does not implement that runtime owner or constitute a ready-to-run semantic probe.

All 58 selected transport, wire, cohort and condition-logic tests passed in 1.26 seconds. The 11 new transport cases cover complete witness retention, four malformed/unconfirmed provider results, malformed completed JSON, request mutation before dispatch, revision change during dispatch, owner cancellation, timeout cancellation without retry, and reply reuse from another request. The timeout test accelerates the timer while asserting the configured 15-second value; it does not measure provider timeout behavior. JUnit is retained at `.venv/condition-query-transport-v1.xml`. Black and diff checks passed.

No model inference, production integration or live configuration change occurred. The next semantic experiment still needs a frozen runtime identity, exact execution and grading files, a durable serial journal, bounded output, and separate grading of states, witness adequacy and final applicability. The native token-cost warning remains: this development representation has not demonstrated the original complete 500 ms requirement. The original quality and pilot gates remain open.
